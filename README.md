# Excel-Style Data Bars in Oracle APEX Interactive Reports

This repository contains the complete implementation used in the blog:

[Excel-Style Data Bars in Interactive Report Blog](https://jefithshalin.blogspot.com/2026/05/excel-data-bars-in-interactive-report.html?utm_source=chatgpt.com)

The solution demonstrates how to create Excel-like in-cell progress bars inside Oracle APEX Interactive Reports using two different approaches without external plugins.

## Overview

Interactive Reports in Oracle APEX are widely used for displaying tabular business data. However, plain numeric values may not always provide quick visual understanding.

This project enhances Interactive Reports by displaying data visually using Excel-style data bars directly inside report columns.

The implementation includes:

* Percentage-based graph columns
* Dynamic HTML progress bars
* Responsive visual indicators
* Lightweight implementation
* No external plugins required
* Fully customizable styles

## Solutions Included

### Solution 01 – Percent Graph Column

This approach uses percentage calculations combined with custom formatting techniques to display visual progress indicators.

#### Features

* Simple implementation
* Fast rendering
* Suitable for percentage-based reports
* Minimal customization required
* Easy maintenance

#### Best Use Cases

* Completion percentage
* KPI indicators
* Performance tracking
* Approval status metrics
* Score visualization

### Solution 02 – Custom HTML Expression

This approach uses custom HTML expressions inside Interactive Reports to generate fully customizable Excel-style data bars.

#### Features

* Fully customizable bar width
* Dynamic colors
* Better visual appearance
* Advanced UI styling
* More flexibility

#### Best Use Cases

* Visual reporting dashboards
